# VELOCITY — Дизайн, интерфейс, анимации

---

## 1. Визуальное направление

**Концепция: «Tactical Dark» — приборная панель гоночного болида, а не «неоновый киберпанк из стоков».**

Почему не киберпанк-неон: он у всех, он быстро надоедает, и он читается как «дешёвый скрипт с Авито». Нам нужно ощущение **точного инструмента**: тёмная база, один акцентный цвет, много воздуха, чёткая типографика, данные на первом плане, анимация как обратная связь, а не как украшение.

Референсы по духу (не для копирования): панель приборов Porsche, интерфейсы Linear и Vercel, HUD из Cyberpunk 2077, оверлей NVIDIA Reflex Analyzer.

### 2.2 Типографика

| Роль | Шрифт | Размеры |
|---|---|---|
| Интерфейс | **Inter** (или Manrope) | 12 / 13 / 14 / 16 / 20 / 28 |
| Цифры и метрики | **JetBrains Mono** или **Geist Mono**, tabular figures | 14 / 18 / 32 / 56 |

### 2.3 Сетка и метрики

- Шаг сетки: **4 px**. Все отступы кратны 4.
- Радиусы: 6 (мелкое) / 10 (карточки) / 16 (модалки) / 999 (пилюли)
- Тени: минимум. Глубина создаётся фоном и границей, а не блюром.
- Границы карточек: 1 px `border-subtle`; при hover — `border-strong` + едва заметное свечение акцентом.
- Минимальное окно: 1100×720. Адаптив до 1440×900 как основной таргет.

## 3. Экраны

### 3.1 Splash (1.5–2 с)

Логотип собирается из линий (SVG path drawing), под ним прогресс-полоса инициализации с реальным текстом: «Подключение к агенту… Чтение конфигурации железа… Проверка лицензии…». Фон — медленно дышащий градиентный меш.

### 3.2 Активация / вход

Центрированная карточка на затемнённом фоне. Поле ключа с **автоформатированием и авто-переходом** между сегментами: `XXXXX-XXXXX-XXXXX-XXXXX`. Вставка из буфера распознаёт ключ с пробелами/переносами.

Состояния: idle → проверка (пульсирующая обводка) → успех (обводка зеленеет, галочка рисуется линией, лёгкий взрыв частиц) → ошибка (короткий шейк, красная обводка, понятный текст: «Ключ уже активирован на 3 устройствах. Сбросить привязку?»).

Внизу: «Продолжить бесплатно» → режим только сканирования.

**Optimization Score** — круговой индикатор, заполняется дугой с градиентом. При первом появлении цифра считает от 0 до значения за 900 мс с ease-out, дуга рисуется синхронно, вокруг — тонкое пульсирующее кольцо цвета текущей зоны.

Формула счёта прозрачна (кликаешь — видишь разбивку):
`Score = 100 − Σ (вес_проблемы × коэффициент_серьёзности)`, по категориям: Дисплей 20, Железо/BIOS 20, GPU 15, Windows 15, Питание 10, Ввод 10, Фон 10.

### 3.4 Сканирование

Полноэкранная анимация с реальным смыслом. По центру — стилизованная схема системы (CPU / GPU / RAM / Диск / Сеть / Дисплей / Ввод), от центра идёт радарная волна, каждый узел при «касании» волной подсвечивается и получает статус: ✓ ок / ! проблема. Слева бежит лог реальных операций.

⚠️ **Никаких фейковых прогресс-баров.** Скан идёт 8–20 с потому, что он реально длится столько (бенчмарк-семпл, ETW-трейс DPC, чтение SMART). Если что-то делается за 200 мс — не растягиваем искусственно.

### 3.6 Применение

Пошаговый список с живым статусом: ожидание → применяется (спиннер) → ✓ применено / ⚠ пропущено / ✗ ошибка. Внизу — консоль лога моноширинным шрифтом, автоскролл, цветовая подсветка. Прогресс — тонкая линия сверху окна.

Финал: сводка «Применено 23 · Пропущено 2 · Ошибок 0», кнопка «Замерить результат», кнопка «Откатить всё».

### 3.7 Бенчмарк (главный экран доверия)

Двухпанельный вид «До / После»:
- Наложенные графики frametime (до — серый, после — акцентный)
- Таблица метрик с дельтами и стрелками: avg FPS, 1% low, 0.1% low, стоттеры, DPC max
- Гистограмма распределения frametime
- Плашка честности: **«Разница в пределах погрешности измерения»**, если дельта меньше доверительного интервала. Это признак серьёзного продукта.

Кнопка «Поделиться результатом» → генерирует красивую картинку 1200×630 с водяным знаком и промокодом → готово к постингу в Discord/Twitter. **Бесплатный вирусный маркетинг.**

### 3.8 Игры

Сетка обложек автоопределённых игр (обложки тянем из Steam CDN / локальных манифестов). У каждой: индикатор «профиль применён», кнопка «Оптимизировать», кнопка «Запустить». Карточка игры → список движковых твиков + рекомендованные внутриигровые настройки для этого железа с ожидаемым FPS.

### 3.9 Твики (Advanced)

Полный каталог: поиск, фильтры (категория, риск, «требует перезагрузки», «применено»), переключатели, массовые операции, экспорт/импорт пресета JSON. Для энтузиастов — режим «показать точное изменение реестра».

### 3.10 Мониторинг

Живые графики: FPS, frametime, загрузка/температура CPU и GPU, VRAM, RAM, сеть. Компактный оверлей-виджет (**реализуем поверх RTSS API или как отдельное always-on-top layered-окно — без хуков в игру**).

### 3.11 Точки восстановления

Хронология изменений. Каждая запись: дата, что применено, снимок Score, кнопки «Откатить всё» / «Откатить выборочно» / «Сравнить с текущим». Плюс большая красная кнопка **«Вернуть систему к состоянию до Velocity»**.

## 4. Анимация

### 4.1 Принципы

1. **Каждая анимация несёт смысл.** Появление = откуда пришло, переход = связь экранов, пульсация = процесс идёт.
2. **Быстро.** Микро 120–180 мс, стандарт 250–320 мс, крупные переходы ≤ 450 мс. Медленная анимация = «тормозной софт».
3. **Кривая по умолчанию** `cubic-bezier(0.2, 0.9, 0.3, 1)` (быстрый старт, мягкий финиш). Для «живых» элементов — spring.
4. **Уважай систему.** Если включено «Отключить анимации» в Windows — выключаем всё автоматически.
5. **Никогда не анимируем во время игры.** Агент детектит фуллскрин-приложение → UI сворачивается в трей, рендер останавливается.

### 4.2 Каталог анимаций

| Элемент | Анимация |
|---|---|
| Переход между разделами | Исходящий: opacity→0, translateX −16px (160 мс). Входящий: opacity 0→1, translateX 16px→0 (240 мс, задержка 80 мс) |
| Score Gauge | Дуга рисуется `stroke-dashoffset` 900 мс ease-out; число считает синхронно; при финале — вспышка свечения 200 мс |
| Карточки рекомендаций | Stagger 40 мс, fade + slide-up 280 мс |
| Toggle | Ручка едет 180 мс spring(0.5, 0.8); фон меняется 150 мс; при включении — расходящееся кольцо акцентом |
| Кнопка (hover) | scale 1.02, свечение 0→24px, 140 мс |
| Кнопка (press) | scale 0.97, 80 мс |
| Успешное применение | Галочка рисуется как path (320 мс) + 12 частиц по дуге (600 мс, gravity ease) |
| Ошибка | Шейк ±6px, 3 колебания, 300 мс + красная вспышка обводки |
| Загрузка данных | Skeleton с диагональным shimmer (1.4 с loop) — **не спиннеры** |
| Радар сканирования | Вращающийся конический градиент 2 с/оборот + пульсирующие кольца от центра |
| Живой график FPS | Плавный сдвиг canvas без перерисовки всей сцены, 60 fps, спайки подсвечиваются красным |
| Toast | Влетает справа снизу spring, авто-скрытие 4 с, свайп для закрытия |
| Модалка | Фон blur 0→12px + затемнение (200 мс); окно scale 0.94→1 + fade (240 мс) |
| Смена темы | Круговое раскрытие новой темы из точки клика (clip-path circle), 500 мс |
| Число метрики | Rolling counter — цифры прокручиваются вертикально, не «прыгают» |

### 4.3 Фоны

Три уровня, переключаются в настройках (важно — приложение об оптимизации не должно жрать ресурсы):

1. **Static** (по умолчанию для слабых ПК) — статичный градиентный меш + плёночное зерно. 0% GPU.
2. **Ambient** — очень медленно дрейфующие радиальные пятна (2 слоя, 60 с цикл) + едва заметная сетка с параллаксом от курсора (смещение ≤ 8 px). ~0.3% GPU.
3. **Reactive** — SkiaSharp/шейдерный фон: частицы, реагирующие на курсор, волна при применении твика, цвет фона слегка сдвигается в сторону цвета текущего Score. ~1–2% GPU, **автоматически отключается при запуске игры**.

Плюс: тонкий слой шума (noise overlay, opacity 3%) поверх всего — убирает «пластиковость» плоских тёмных поверхностей. Дешёвый приём с огромным эффектом на восприятие качества.

### 4.4 Бюджет производительности самого приложения

Иронично, но критично — оптимизатор, который тормозит, не купят.

| Метрика | Лимит |
|---|---|
| RAM в простое | < 90 МБ |
| RAM с открытым мониторингом | < 160 МБ |
| CPU в простое (свёрнуто в трей) | < 0.3% |
| CPU при активном UI | < 3% |
| GPU при фоне Ambient | < 1% |
| Во время игры | UI-рендер полностью остановлен, работает только сборщик метрик |
| Размер установщика | < 60 МБ |
| Холодный старт | < 1.5 с до интерактивности |

## 5. Звук (опционально, по умолчанию тихо)

Короткие, глухие, «приборные» звуки: клик тумблера, мягкий тик при появлении карточки, восходящий аккорд при завершении оптимизации, низкий тон при ошибке. Всё ≤ 200 мс, −18 dB. Переключатель в настройках, **по умолчанию выключено** (никто не любит, когда софт неожиданно звучит).

## 6. Копирайтинг (тон голоса)

**Правило: говорим как знающий друг, а не как маркетинговый буклет.**

| ❌ Плохо | ✅ Хорошо |
|---|---|
| «Оптимизация системы завершена! Прирост производительности до 300%!» | «Готово. Применили 23 настройки. Замерим результат?» |
| «Обнаружены критические ошибки реестра!» | «Монитор 165 Гц работает на 60 Гц. Это самая заметная находка.» |
| «Очистка мусора освободила 4.2 ГБ!» | «Освободили 4.2 ГБ. На FPS это не влияет, но место лишним не бывает.» |
| «Ускорьте свой ПК прямо сейчас!» | «Твоя система в неплохой форме — нашли 4 вещи, которые стоит поправить.» |

**Всегда объясняем «почему»**, а не только «что». Каждый твик отвечает на вопрос «а зачем это?» одним предложением на человеческом языке.

**Не обещаем цифры, которых не измерили.** Вместо «+40% FPS» — «обычно даёт +5–12 FPS на похожем железе». А после бенчмарка — точную дельту.

## 7. Иконки и графика

- Иконки: **Lucide** или **Phosphor** (тонкие, 1.5px stroke) — единый набор, никакого микса стилей
- Логотип: монограмма из угловых линий, читается в 16×16 (иконка трея)
- Иллюстрации пустых состояний: минималистичные линейные, одним акцентным цветом
- Обложки игр: тянем из официальных источников
- Все ассеты — векторные (XAML Path / SVG), чтобы не мылить на 150% DPI

## 8. Доступность и мелочи, которые заметны

- Полная навигация с клавиатуры, видимый focus ring
- Контраст текста ≥ 4.5:1 (проверить `text-tertiary` на `bg-surface`)
- Поддержка масштабирования Windows 100/125/150/175/200%
- Корректная работа при смене DPI на лету (перенос окна между мониторами)
- Уважение системной настройки «Уменьшить движение»
- Правильные курсоры, tooltip с задержкой 500 мс
- Ctrl+F — глобальный поиск по твикам
- Окно запоминает размер и позицию
- Двойной клик по иконке трея — восстановление; ПКМ — быстрое меню (Gaming Mode, Скан, Выход)
