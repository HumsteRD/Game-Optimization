# VELOCITY — Лицензирование, защита, продажи

---

## 0. Философия защиты

**Твой софт взломают. Это данность, не вопрос.** Любое десктопное приложение, где проверка идёт на клиенте, ломается — вопрос только в том, за сколько часов.

Поэтому цель системы лицензий — **не «сделать невзламываемо»**, а:

1. Не дать одному купленному ключу разойтись по 500 людям (99% реальных потерь — это шаринг ключей, а не реверс-инжиниринг)
2. Сделать кряк **хуже оригинала** — держать ценность на сервере
3. Не мешать честному покупателю (офлайн-режим, смена железа, переустановка Windows)

### Что держим на сервере (кряк это не получит)

- **Каталог твиков** — обновляется еженедельно, с новыми правилами под новое железо и патчи Windows
- **Профили игр** — обновляются под патчи движков
- **База сравнения** («у похожего железа медиана 178 FPS»)
- **Cloud-пресеты комьюнити**
- **Диагностическая база драйверов** (какой драйвер даёт DPC-спайки)

Кряк даёт замороженный снимок на день релиза. Через 2 месяца он объективно устарел. Это работает лучше любой обфускации.

**Не тратить время на:** VMProtect/Themida (ломает антивирусы + false positive + всё равно снимают), кастомные паковщики, анти-отладку. Это отрицательный ROI.

**Разумный минимум:** обфускация (Obfuscar/ConfuserEx для .NET) или **NativeAOT-компиляция** критичных сборок, проверка целостности подписи собственных файлов, отсутствие одной-единственной точки `if (isLicensed)`.

## 1. Формат ключа

```
VLCT-A7K3M-9QX2P-R5T8W-N4H6D
```

- Префикс `VLCT` — тип продукта (можно варьировать: `VLCP` Pro, `VLCL` Lifetime, `VLCS` Squad, `VLCG` подарочный/промо)
- 5 групп по 5 символов, **алфавит Crockford Base32** (без `I`, `L`, `O`, `U` — исключены символы, которые путают при вводе с рук)
- Внутри закодировано: `product_id | tier | issued_at | serial | checksum`
- Последние символы — **подпись Ed25519** усечённого payload

**Зачем подпись:** приложение может отсеять мусорные/выдуманные ключи офлайн, мгновенно, без запроса к серверу. Валидность именно этой копии всё равно подтверждает сервер, но 99% «случайного перебора» отсекается локально.

Регистр ввода не важен, дефисы проставляются автоматически, вставка из буфера чистит пробелы и переносы.

## 2. HWID — привязка к устройству

### Проблема наивной реализации

Большинство «самописных» лицензий берут один идентификатор (например, серийник диска) и намертво к нему привязываются. Итог: человек поменял SSD → лицензия сгорела → возврат и негатив.

### Наше решение: нечёткое совпадение по компонентам

Собираем 6 компонентов, каждый хэшируем отдельно (SHA-256 с солью продукта):

| # | Компонент | Источник | Вес | Стабильность |
|---|---|---|---|---|
| 1 | UUID материнской платы | SMBIOS / `Win32_ComputerSystemProduct.UUID` | 3 | очень высокая |
| 2 | CPU ID + модель | CPUID | 2 | высокая |
| 3 | MachineGuid | `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid` | 2 | средняя (меняется при переустановке ОС) |
| 4 | Серийник системного накопителя | `Win32_DiskDrive.SerialNumber` | 2 | средняя |
| 5 | MAC первого физического адаптера | `Win32_NetworkAdapter` (только не-виртуальные) | 1 | средняя |
| 6 | Модель GPU | DXGI adapter desc | 1 | средняя |

Итого максимум **11 баллов**.

**Правило совпадения:** устройство считается тем же, если совпало **≥ 7 баллов** и обязательно совпал компонент №1 **или** №2.

Это переживает: замену диска, смену видеокарты, добавление RAM, переустановку Windows, замену сетевой карты. И не переживает: полную смену платформы (что и требуется).

При «частичном совпадении» (5–6 баллов) сервер **автоматически обновляет** запись устройства и логирует событие — это апгрейд, а не новый ПК.

### Слоты устройств

| Тариф | Слотов |
|---|---|
| Pro | 2 |
| Lifetime | 3 |
| Squad | 3 (позиционируется как «для команды») |

**Самообслуживание:** пользователь может освободить слот сам — из приложения («Отвязать это устройство»), из личного кабинета или через Telegram-бота. Ограничение: не чаще **2 сбросов в 30 дней**. Это снимает 90% обращений в поддержку и не даёт крутить ключ по друзьям.

## 3. Протокол лицензирования

### Активация

```
Клиент → POST /v1/activate
{
  "key": "VLCT-A7K3M-9QX2P-R5T8W-N4H6D",
  "hwid_components": { "mb": "...", "cpu": "...", "guid": "...", ... },
  "app_version": "1.0.3",
  "os": "10.0.26100",
  "nonce": "<random 32B>"
}

Сервер → 200 OK
{
  "token": "<Ed25519-signed JWT>",
  "tier": "lifetime",
  "expires_at": null,
  "grace_until": "2026-08-15T00:00:00Z",
  "features": ["tweaks", "profiles", "benchmark", "cloud"],
  "device_slot": 1,
  "slots_total": 3
}
```

### Оффлайн-токен

Токен подписан **Ed25519**, публичный ключ вшит в приложение. Внутри: `key_id`, `hwid_hash`, `tier`, `features`, `issued_at`, `grace_until`, `nonce`.

Клиент проверяет подпись локально при каждом запуске. **Пока `grace_until` не истёк — интернет не нужен вообще.**

- Grace-период: **14 дней**
- Продление: при каждом успешном heartbeat
- Heartbeat: раз в 24 ч, тихо, в фоне; сбой не мешает работе

**Это важно.** Человек играет в самолёте/на даче/у него лёг провайдер — продукт обязан работать. Софт, который «требует интернет для запуска» ради DRM, получает 1 звезду и лавину крэков.

### Отзыв

Сервер может пометить ключ `revoked` (чарджбэк, возврат, обнаружен шаринг). При следующем heartbeat токен не продлевается, после истечения grace приложение мягко переходит в Free-режим — **не блокируется, не удаляет данные, откат твиков остаётся доступным всегда**.

### Защита канала

- HTTPS + **certificate pinning** (иначе кряк просто подменит DNS на локальный «сервер»)
- Подпись запросов HMAC на общем секрете сборки
- Ответ содержит `nonce` из запроса — защита от replay
- Rate limiting: 10 попыток активации на IP в час, 5 на ключ в сутки

## 4. Серверная часть

### Стек

**ASP.NET Core Minimal API + PostgreSQL + Redis** (либо FastAPI + PostgreSQL, если тебе привычнее Python — у тебя уже есть опыт с ботами). Разворачивается на существующем немецком VPS.

### Схема БД

```sql
products      (id, slug, name, default_slots)
licenses      (id, key_hash, product_id, tier, status, issued_at,
               expires_at, max_devices, owner_email, order_ref, notes)
devices       (id, license_id, hwid_components jsonb, fingerprint,
               first_seen, last_seen, os, app_version, revoked)
activations   (id, license_id, device_id, ip, ua, result, created_at)
resets        (id, license_id, device_id, created_at, source)
orders        (id, provider, provider_order_id, amount, currency,
               status, license_id, buyer_contact, created_at)
tweak_catalog (id, version, payload jsonb, min_app_version, published_at)
game_profiles (id, slug, version, payload jsonb, published_at)
telemetry     (id, install_id, event, payload jsonb, created_at)   -- анонимно
```

> **Ключи храним только как хэш** (`key_hash`, Argon2id или SHA-256 с перцем). Утечка БД не должна раздавать рабочие ключи.

### Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/v1/activate` | Активация |
| POST | `/v1/heartbeat` | Продление токена |
| POST | `/v1/deactivate` | Освобождение слота |
| GET | `/v1/catalog?since=` | Инкрементальные обновления твиков |
| GET | `/v1/profiles?since=` | Профили игр |
| GET | `/v1/updates?channel=` | Проверка обновлений (манифест подписан) |
| POST | `/v1/telemetry` | Анонимная статистика (только при opt-in) |
| POST | `/v1/baseline` | Запрос медианы по похожему железу |
| POST | `/hooks/{provider}` | Вебхуки платёжек → выдача ключа |
| — | `/admin/*` | Админка (JWT + 2FA) |

### Админка

Список лицензий с поиском · выдача/отзыв/продление · просмотр устройств · **детектор шаринга** (много разных HWID + разные страны по IP за короткий срок) · возвраты · статистика продаж · публикация каталога твиков · рассылка через Telegram-бота.

### Реферальная программа (сильно недооценена в игровом комьюнити)

- Стример получает промокод: покупателю −20%, автору 30% от суммы
- Личный кабинет с статистикой переходов и выплат
- Выплаты раз в 2 недели
- Дополнительно — «поделись результатом бенчмарка» генерирует картинку с промокодом автора

Для игрового комьюнити это конвертит лучше любой платной рекламы.

### Триал / Free-режим

**Не делаем классический триал.** Вместо него — вечно бесплатный режим сканирования:

- Полный скан и диагностика — **бесплатно, навсегда**
- Мониторинг и бенчмарк — бесплатно
- Показ всех найденных проблем с описанием — бесплатно
- **Применение исправлений** — Pro

Человек своими глазами видит: «монитор работает на 60 Гц вместо 165», «RAM на 2133 вместо 3600», «драйвер Wi-Fi даёт фризы». Он уже знает, что продукт прав. Конверсия такой воронки — 8–15% против 1–2% у обычного триала.

Исключение: **одно бесплатное исправление** (самая критичная находка) — чтобы человек почувствовал результат до оплаты.

### Возвраты

**14 дней без вопросов.** Да, часть людей злоупотребит. Но публичная политика «вернём деньги, если не помогло» снимает главное возражение при покупке малоизвестного софта и даёт больше продаж, чем теряет на возвратах.

## 6. Реализация проверки в клиенте (правильно)

### ❌ Как не надо

```csharp
if (!license.IsValid) return;   // одна точка — снимается за 10 минут
```

### ✅ Как надо

1. **Проверка размазана** — валидность влияет на разные подсистемы в разных местах, не одним булевым флагом
2. **Данные зависят от лицензии** — часть каталога твиков и профили игр приходят с сервера, зашифрованные ключом, производным от токена. Нет валидного токена → нечего расшифровывать → нечего применять. Это не «проверка», которую можно вырезать; это отсутствие данных
3. **Отложенная реакция** — если целостность нарушена, не падаем сразу с криком «пиратка». Просто на следующем запуске не приходят обновления каталога. Отладка кряка усложняется многократно
4. **Проверка целостности собственных файлов** через Authenticode-подпись
5. **Критичный код в NativeAOT-библиотеке**, а не в managed-сборке
6. **Никогда не показываем агрессивные окна «ПИРАТСКАЯ КОПИЯ»** — иногда срабатывает ложно на честном пользователе, и это мгновенный репутационный удар

### Хранение токена

`%LOCALAPPDATA%\Velocity\license.dat`, зашифрован **DPAPI** (`CurrentUser` scope) — привязан к профилю Windows, не переносится копированием файла на другой ПК.

## 7. Обновления

- Канал: `stable` / `beta`
- Манифест подписан Ed25519, клиент проверяет подпись **до** распаковки
- Дельта-обновления для каталога твиков (JSON, часто) и полные — для бинарников (редко)
- Каталог твиков и профили игр обновляются **без переустановки приложения** — это ключ ко всей модели ценности
- Откат на предыдущую версию, если новая упала при старте (счётчик неудачных запусков)

## 8. Юридическая часть

Обязательный минимум перед первой продажей:

1. **EULA** — лицензия на использование, а не продажа софта; запрет реверса и перепродажи; ограничение по количеству устройств
2. **Отказ от гарантий** — «ПО предоставляется "как есть"; изменения системных настроек производятся пользователем на свой риск; рекомендуем сохранять точку восстановления»
3. **Политика конфиденциальности** — что собираем (конфигурация железа анонимно, только при согласии), что НЕ собираем (личные файлы, история браузера, скриншоты)
4. **Политика возврата** — 14 дней
5. **Дисклеймер о брендах** — «Не аффилированы с Microsoft, NVIDIA, AMD, Intel, Valve, Riot Games. Все торговые марки принадлежат их владельцам»
6. **Дисклеймер об античитах** — «ПО не взаимодействует с игровыми процессами и не внедряет код. Тем не менее, применение настроек производится на ответственность пользователя»
7. **Оформление приёма платежей** — самозанятость или ИП для легального приёма денег в РФ

При первом запуске — экран принятия EULA с чекбоксом. Версию принятой EULA храним.
