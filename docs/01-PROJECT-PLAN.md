# VELOCITY — План проекта

> Рабочее название. Альтернативы: **VELOCITY**, **APEX Tune**, **RAWINPUT**, **Coldboot**, **NULLPING**, **Frametime**.
> Рекомендую **VELOCITY** — короткое, произносимое на русском и английском, свободный домен-нейминг (velocity.gg / velocitytune.io), хорошо ложится на логотип.

---

## 0. Позиционирование (самое важное решение проекта)

### Проблема рынка

Все существующие «оптимизаторы» (Razer Cortex, Advanced SystemCare, Wise Game Booster, десятки TG-шных «тюнеров» за 500₽) делятся на два типа:

1. **Плацебо-софт** — чистит кэш, «освобождает RAM» (что вредно), крутит мёртвые твики (`disabledynamictick`, отключение SysMain, `IRQ8Priority`), рисует красивый график «+37% производительности», взятый из воздуха.
2. **Скрипты-помойки** — .bat/.reg паки, которые ломают систему без отката, палятся античитами, и после них человек переустанавливает Windows.

**Ни один не измеряет результат.** Пользователь платит и не знает, стало ли лучше.

### Наше УТП

> **«Оптимизация, которую можно доказать»**

Три столпа:

| Столп | Что это | Почему конкуренты не могут |
|---|---|---|
| **Измеримость** | Замер frametime до/после через ETW (PresentMon). Показываем avg FPS, 1% low, 0.1% low, счётчик стоттеров, DPC latency. Реальная дельта в цифрах. | Требует серьёзной инженерии, а не .bat-скрипта |
| **Железо-зависимость** | Твики применяются по правилам: X3D-процессор → пиннинг на кэш-CCD; Intel 12+ → P-core affinity для старых игр; NVIDIA → NVAPI-профиль; ноут → другой power plan | Требует полноценного детекта железа |
| **Честность** | Есть раздел «Мифы» — прямо показываем твики, которые НЕ работают, и почему мы их не делаем. Это лучший маркетинг доверия. | Им нечего продавать без мифов |

### Что мы принципиально НЕ делаем

Это не ограничение — это **техническая безопасность и продаваемость**:

- ❌ **Никаких инъекций в процесс игры**, никаких хуков, никаких записей в память игры
- ❌ **Никакого kernel-драйвера собственной разработки** (мгновенный бан в Vanguard/FACEIT + кошмар с подписью WHQL)
- ❌ **Не отключаем Defender** (это делают вирусы; вместо этого — исключения папок игр, что даёт реальный эффект)
- ❌ **Не «чистим RAM»** (Windows управляет памятью лучше)
- ❌ **Не удаляем системные компоненты Windows** без явного отдельного согласия

**Результат:** приложение античит-безопасно by design. Все изменения применяются, когда игра НЕ запущена. Это прямо пишем на лендинге — это конкурентное преимущество, а не оправдание.

## 1. Целевая аудитория

| Сегмент | Доля | Что им нужно | Триггер покупки |
|---|---|---|---|
| **Соревновательные игроки** (CS2, Valorant, Apex, Fortnite) | ~45% | 1% low, стабильный frametime, input lag | «Микрофризы в клатчах» |
| **Владельцы слабых/старых ПК** | ~30% | Любые +10 FPS чтобы играть | «Не тянет игру» |
| **Владельцы мощных ПК** | ~15% | «Я заплатил 300к, почему просадки?» | «Железо топ, а FPS плавает» |
| **Ноутбучники** | ~10% | Тротлинг, гибридная графика, питание | «На зарядке норм, без — 20 FPS» |

**Ключевой инсайт для конверсии:** бесплатный скан находит вещи, от которых у человека отвисает челюсть:
- «Твой монитор 165 Гц, но Windows выставила 60 Гц» (встречается у ~15% людей)
- «RAM работает на 4800 МГц вместо заявленных 6000 — XMP/EXPO выключен в BIOS» (~35% сборок!)
- «Игра запускается с HDD, а на SSD 400 ГБ свободно»
- «Драйвер `rtwlanu.sys` даёт DPC latency 2100 мкс — это твои фризы»

Эти находки — **бесплатны**. Исправление — платно. Это лучшая воронка, чем любая реклама.

- [x] Автообновление

- Детект тротлинга (термо/power limit)

- Cloud-профили: комьюнити шарит пресеты, мы модерируем и раздаём («CS2 на RTX 3060 + i5-12400F — 847 человек используют»)
- Auto-Pilot: фоновый агент подстраивает систему при запуске игры и возвращает всё после выхода
- Undervolt-ассистент (только советы + профили MSI Afterburner, сами не крутим)
- Сравнение с базой: «твоя сборка выдаёт 143 FPS, медиана по такому железу — 178, вот 5 причин»
- Реферальная программа для стримеров

## 3. Технический стек

### Решение: **.NET 9 + WPF** (основной вариант)

| Слой | Технология | Почему |
|---|---|---|
| UI | WPF + кастомная дизайн-система, `Lottie` (LottieSharp) для анимаций, `SkiaSharp`/Win2D для фонов и графиков | Полный контроль над анимацией, аппаратное ускорение, зрелость |
| Ядро | C# .NET 9, DI (Microsoft.Extensions.Hosting) | Лучший доступ к WinAPI/WMI/реестру среди «удобных» стеков |
| Привилегии | Отдельный процесс `Velocity.Agent` (Windows Service, подписанный) ↔ named pipe с whitelist команд | UI не требует админа; агент не выполняет произвольный код |
| Нативка | P/Invoke: `nvapi64.dll`, `atiadlxx.dll`, `setupapi`, `powrprof`, `d3dkmt`, `ChangeDisplaySettingsEx`, `NtSetTimerResolution` | Прямой доступ без прослоек |
| Телеметрия перфа | Intel **PresentMon** (MIT) — ETW-консьюмер, встраиваем как библиотеку/подпроцесс | Индустриальный стандарт замера frametime |
| Сенсоры | `LibreHardwareMonitorLib` — **но см. риск ниже** | Температуры, вольтаж, тротлинг |
| Хранилище | SQLite (снапшоты, история бенчмарков, кэш профилей) | Ноль зависимостей |
| Бэкенд лицензий | ASP.NET Core Minimal API или FastAPI + PostgreSQL | См. `04-LICENSING.md` |
| Установщик | Inno Setup или MSIX | Inno гибче для сервисов |

**⚠️ Риск с LibreHardwareMonitor:** он грузит драйвер `WinRing0`, который (а) есть в блоклисте уязвимых драйверов Microsoft, (б) блокируется Riot Vanguard, (в) триггерит часть антивирусов. **Решение:** сенсоры — опциональный модуль, выключен при обнаружении Vanguard/EAC/FACEIT; альтернатива — читать shared memory HWiNFO64, если он установлен, и Windows perf counters для базовых метрик.

### Альтернатива: **Rust + Tauri v2 + React**

Взять, если приоритет — визуал и размер бинарника.

- ➕ Лучший UI за меньшие усилия (React + Framer Motion + GSAP = вау-анимации из коробки), бинарь ~8 МБ, сложнее реверсить
- ➖ WinAPI-работа через `windows-rs` многословнее, NVAPI придётся биндить руками, меньше готовых библиотек мониторинга

**Мой выбор: .NET 9 + WPF.** Причина простая — 70% ценности проекта в глубине работы с системой, а не в UI. Красивый UI на WPF делается, просто дороже. Но если у тебя есть фронтендер — Tauri выигрывает.

### Модули

**HardwareScanner** — собирает полный отпечаток системы:
CPU (модель, ядра P/E, CCD, L3, микрокод, виртуализация), GPU (модель, VRAM, версия драйвера, ReBAR, шина PCIe и её текущая ширина/линк-скорость), RAM (объём, каналы, текущая частота, тайминги, тип), накопители (тип, интерфейс, свободное место, драйвер NVMe), дисплеи (разрешение, текущая/максимальная частота, VRR, HDR, битность), мышь/клавиатура (VID/PID, измеренный polling rate, USB-хаб и его версия), ОС (билд, VBS/HVCI, Game Mode, план питания, timer resolution), BIOS-фичи (Secure Boot, CSM, TPM, SVM/VT-x, ReBAR).

**TweakEngine** — исполнитель декларативных твиков (см. `02-OPTIMIZATION-SPEC.md`).
Каждый твик — это данные, не код. Значит: обновляются с сервера без переустановки приложения.

**SnapshotEngine** — перед ЛЮБЫМ изменением:
1. Создать точку восстановления Windows (раз в сессию, не чаще)
2. Экспортировать затрагиваемые ветки реестра в `.reg`
3. Записать в SQLite полное состояние «до» для каждого изменённого ключа
4. Отдельно бэкапить оригиналы игровых конфигов

Откат — атомарный, по одному твику или всё целиком, из UI и из отдельного `Velocity.Rescue.exe` (работает даже если основное приложение сломалось).

**BenchmarkEngine** — ETW-захват через PresentMon:
- Режим «в игре»: пользователь играет 60–120 сек, мы пишем frametime
- Метрики: avg FPS, 1% low, 0.1% low, frametime variance, stutter events (кадры >2× медианы), input latency (если есть Reflex/Anti-Lag)
- Сравнение сессий с доверительным интервалом — не показываем «+3 FPS», если это в пределах шума

**GameProfileEngine** — детект установленных игр (Steam `libraryfolders.vdf`, Epic manifests, EA/Ubisoft, реестр Uninstall, сканирование по известным exe), применение движковых твиков.

## 5. Дорожная карта (реалистичная)

| Неделя | Что делаем | Артефакт |
|---|---|---|
| 1–2 | HardwareScanner + модель данных + SQLite | Консольная утилита, выдающая полный JSON-отчёт о системе |
| 2–3 | Схема твиков + TweakEngine + SnapshotEngine/Restore | 15 твиков применяются и откатываются |
| 3–4 | Agent-сервис + IPC + установщик + подпись кода | Ставится, работает без прав админа у UI |
| 4–6 | UI-каркас, дизайн-система, экраны Dashboard/Scan/Apply | Кликабельное приложение |
| 5–6 | BenchmarkEngine (PresentMon ETW) | Замер до/после работает |
| 6–7 | Лицензирование: сервер + клиент + Telegram-бот продаж | Можно продать первый ключ |
| 7–8 | Каталог до 40 твиков, полировка, closed beta (20–30 человек) | **MVP-релиз** |

**Closed beta обязательна.** Собери 20–30 человек с разным железом (обязательно: ноут, AMD GPU, Intel iGPU, Win10, X3D, старый Ryzen). Твики, работающие на твоём ПК, могут положить чужой.

## 6. Риски и как их снимаем

| Риск | Вероятность | Последствие | Митигация |
|---|---|---|---|
| **SmartScreen блокирует установщик** | Очень высокая | −80% конверсии | Купить **code signing сертификат** (OV ~$200–400/год, EV ~$400–600/год с мгновенной репутацией). Это не опция, это обязательная статья бюджета. |
| **Антивирусы дают false positive** | Высокая | Возвраты, репутация | Не использовать пакеры/криптоворы, подписывать всё, заранее отправить билды в VirusTotal + формы false-positive Microsoft/Kaspersky/Avast/ESET |
| **Античит банит** | Средняя (если делать глупости) | Смерть проекта | Архитектурный запрет: без инъекций, без драйверов, без записи в память игр, все изменения — вне игровой сессии. Оверлей — только через сторонний RTSS API или вообще отдельное окно, не хук. |
| **Сломали чью-то систему** | Средняя | Возвраты, негатив | Точки восстановления, `Velocity.Rescue.exe`, риск-уровни у твиков, «безопасный» пресет по умолчанию |
| **Пиратство / кряк** | Гарантированная (100%) | Потеря части выручки | Не воевать. Держать ценность на сервере (база профилей, cloud-пресеты, обновления твиков). Кряк даёт «замороженную» версию. См. `04-LICENSING.md` |
| **Твик работает у одного, ломает у другого** | Высокая | Поддержка тонет | Каждый твик имеет `requires` (условия железа) и телеметрию успешности; автоотключение твика в облаке, если растёт % откатов |
| **Юридические претензии** | Низкая | — | EULA, дисклеймер «без гарантий», «не аффилированы с Microsoft/NVIDIA/AMD», политика возврата, ИП/самозанятость для приёма платежей |

## 7. Монетизация

### Тарифы

| Тариф | Цена (RU) | Цена (Global) | Что входит |
|---|---|---|---|
| **Free** | 0₽ | $0 | Полный скан + отчёт о проблемах + мониторинг. **Ничего не применяет.** |
| **Pro (год)** | 890₽ | $14.99 | Все твики, профили игр, бенчмарк, откат, обновления |
| **Lifetime** | 1 890₽ | $29.99 | То же навсегда + приоритет в саппорте |
| **Squad (3 ПК)** | 3 490₽ | $54.99 | 3 устройства, для команд/семьи |

**Почему Free-скан обязателен:** человек видит «RAM работает на 4800 вместо 6000», «монитор 165 Гц выставлен на 60», «драйвер Wi-Fi даёт фризы» — и покупает сам. Это конверсия 8–15% против 1–2% у обычного триала.

### Каналы продаж

1. **Telegram-бот** — основной для RU. Оплата → бот выдаёт ключ. Ты уже делал ботов, это твой самый быстрый путь.
   Эквайринг: Lava.top / CryptoCloud / Telegram Stars / ЮKassa (если есть ИП/самозанятость)
2. **Лендинг** + Digiseller/Enot для RU, **LemonSqueezy или Paddle** для международки (они merchant of record — сами платят НДС/VAT, тебе не надо оформлять налоги в 40 странах)
3. **Реферальная система для стримеров/ютуберов**: промокод даёт −20% покупателю и 30% автору. Для игрового комьюнити это работает лучше рекламы.

### Маркетинг

- YouTube/Twitch: «Я вытащил +40 FPS из этого ПК за 3 минуты» — с реальным замером на экране, наш бенчмарк-скрин как пруф
- Reddit r/pcmasterrace, r/optimization, 4PDA, Overclockers.ru, Pikabu
- Discord-сервер с бесплатной помощью в оптимизации (там же продажи)
- Публичный раздел «Мифы оптимизации» на сайте — это SEO-магнит и доверие
