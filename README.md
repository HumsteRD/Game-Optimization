## Что это

Рынок «оптимизаторов» состоит из плацебо с фейковыми графиками и .bat-паков, после которых люди переустанавливают Windows. VELOCITY построена на трёх правилах:

**Ничего необратимого.** Перед любым изменением состояние системы записывается на диск. Откат возвращает значения ровно такими, какими они были — включая те, которых до изменения вообще не существовало.

**Ничего недоказуемого.** Каждая настройка объясняет, что именно она меняет и какого эффекта ждать. Никаких «+300% FPS». Там, где эффект неоднозначный, так и написано.

**Ничего опасного для античитов.** Без внедрения в процессы игр, без драйверов в ядре, без чтения памяти. Все изменения применяются при закрытой игре, а при активном античите программа отказывается работать.

## Возможности

### Диагностика

Скан занимает около **200 мс** и находит то, что обычно остаётся незамеченным годами:

| Находка | Насколько часто |
|---|---|
| Монитор 165 Гц работает на 60 Гц | примерно у каждого седьмого |
| XMP/EXPO выключен — память на базовой частоте JEDEC | примерно у трети сборок |
| Память в одноканальном режиме при двух планках | часто после самостоятельной сборки |
| Игры на жёстком диске при наличии SSD | очень часто |
| Пять оверлеев одновременно в цепочке вывода кадра | почти у всех |
| Следы вредных твиков от прошлого «оптимизатора» | у тех, кто уже пробовал лечиться |

Определяются: топология процессора с P/E-ядрами и CCD (включая асимметричный кэш X3D), настоящий объём видеопамяти, вендорская версия драйвера NVIDIA, все доступные режимы мониторов, библиотеки Steam/Epic/Xbox с типом накопителя под каждой игрой, состояние VBS, HVCI, HAGS, Game DVR, MMCSS и разрешения системного таймера.

### Оптимизация

**42 настройки** в шести наборах — от «Безопасного», который не меняет поведение системы, до «Экстремального» с отключением защитных механизмов Windows ради кадров.

Настройки драйвера NVIDIA применяются через **NVAPI** — тот же механизм, которым пользуется панель управления NVIDIA. Настройки AMD — через ключи драйвера в реестре.

Каждая настройка знает, подходит ли она этой системе: правила вида `gpu.vendor=nvidia`, `cpu.is_x3d=true`, `os.build>=22000` проверяются до показа, и неподходящее просто не появляется в списке.

### Очистка диска

Диаграмма занятости показывает, чем реально занято место, и отдельно помечает папки с играми. Поиск мусора находит кэш шейдеров видеодрайвера (он дорастает до десятков гигабайт и почти никогда не чистится сам), распакованные установщики драйверов, временные файлы, остатки обновлений Windows и кэши лаунчеров.

Список путей закрытый и составлен вручную: программа не ищет «ненужные файлы» по своему усмотрению и не пользуется масками. Каждая категория объясняет, что произойдёт после удаления, а отмечено по умолчанию только заведомо безопасное.

### Профили игр

Движковые настройки дают больше кадров, чем любые системные твики. Для CS2, Valorant, Apex, Dota 2, Fortnite, GTA V, Rust, Minecraft и общего профиля Unreal Engine собраны параметры запуска, правки конфигов и настройки, которые надо выставить в самой игре — с объяснением, почему именно так.

Советы фильтруются по железу: «снизь качество текстур из-за нехватки видеопамяти» не показывается владельцу карты на 16 ГБ.

## Установка

**[Скачать установщик](https://github.com/HumsteRD/Game-Optimization/releases/latest/download/velocity-setup-0.3.0.exe)** (52 МБ) и запустить. Программа ставится **без запроса прав администратора** — права запрашиваются отдельно и только в момент, когда пользователь применяет настройки, которым они действительно нужны.

.NET устанавливать не надо, всё уже внутри. Требуется Windows 10 версии 2004 или новее, 64 бита.

При первом запуске Windows покажет предупреждение SmartScreen — файл пока без цифровой подписи. «Подробнее» → «Выполнить в любом случае».

Проверить, что файл не подменён по дороге:

```
CertUtil -hashfile velocity-setup-0.3.0.exe SHA256
```

```
ea741eb39d1986b0dc15d6e63e5c69da5b0506c02a8bdb41b70944273a4b9fec
```

## Сборка из исходников

Нужен .NET 9 SDK.

```bash
dotnet build
```

```bash
dotnet run --project src/Velocity.App
```

Самопроверка перед выпуском — проверяет каталог, сканер и полный цикл применения с откатом на живой системе:

```bash
dotnet run --project tests/Velocity.SelfCheck
```

Сборка установщика (нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)):

```bash
dotnet publish src/Velocity.App -c Release -o dist-app && ISCC installer/velocity.iss
```

## Устройство

```
src/
  Velocity.Core/        модели отчёта, находки, формула оценки, русские числительные
  Velocity.Hardware/    сканеры железа, движок находок, замер частоты опроса мыши
  Velocity.Tweaks/      движок применения, снимки и откат, каталог, профили игр
  Velocity.App/         интерфейс на WPF
  Velocity.Scan.Cli/    консольный сканер для диагностики и поддержки
tests/
  Velocity.SelfCheck/   самопроверка перед выпуском
installer/              скрипт Inno Setup
docs/                   план проекта, спецификация оптимизации, дизайн, лицензирование
```

**Твик — это данные, а не код.** Каталог лежит в JSON, поэтому правила обновляются без переустановки программы. Движок умеет пять видов действий: реестр, схемы питания, режимы дисплея, режим запуска служб, профиль драйвера NVIDIA и команды из закрытого белого списка.

Порядок применения жёсткий и нарушать его нельзя:

```
проверка условий → снятие снимка → применение → проверка результата
                                        ↓ не сошлось
                                   откат этого твика
```

Снимок пишется на диск после каждого твика, а не в конце: если программа упадёт посреди применения, откатить всё равно будет можно.

## Чего программа не делает

Не внедряется в процессы игр и не читает их память. Не ставит драйверы в ядро. Не отключает Защитник Windows (вместо этого — исключения папок игр, тот же эффект без дыры в безопасности). Не «чистит» оперативную память. Не удаляет системные службы — только переводит в ручной запуск. Не применяет команды, для которых в каталоге не описан откат.

Это осознанные ограничения. Именно они делают программу безопасной для античитов.

## Обновления

Программа раз в сутки спрашивает у GitHub, не вышла ли новая версия. Проверку и автоматическую загрузку можно выключить в настройках. Прерванная загрузка продолжается с того места, где остановилась, а не начинается заново.

## Известные ограничения

- Замер FPS до и после пока не реализован
- Скорость линии PCIe видеокарты не читается — нужен NVAPI/ADL
- Температуры и троттлинг недоступны без драйвера-сенсора, а популярный `WinRing0` блокируется Vanguard и рядом антивирусов
- XMP/EXPO определяется эвристикой по базовым частотам JEDEC: без чтения SPD по шине SMBus точнее не выйдет
- Каналы памяти разбираются из имён слотов; при нестандартных именах возвращается «неизвестно», а не догадка
- Исполняемый файл без цифровой подписи, SmartScreen будет предупреждать при первом запуске
